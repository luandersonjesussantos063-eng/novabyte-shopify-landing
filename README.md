# NovaByte Shopify Landing

Protótipo **independente** de landing page de produto único, em italiano, para aprovação visual antes da instalação na Shopify do cliente.

## Visualização
Abra `index.html` no navegador ou habilite GitHub Pages se desejar uma prévia web. Nenhum checkout está conectado nesta versão.

## Personalização pendente
- Nome, fotos, benefícios comprovados e preço real do produto
- Vídeo publicitário fornecido pelo cliente
- Condições reais de frete, devolução e suporte
- Integração Shopify Liquid com produto/variantes, carrinho e checkout
- Revisão de italiano, acessibilidade e testes móveis

## Segurança
Não inserir credenciais Shopify no repositório. Não publicar alegações, depoimentos ou descontos fictícios. Trabalhar em tema de rascunho na Shopify, sem alterar a loja ativa.
